## How to use this pack
Copy the contents into the root of the Spirit Guide repository so that `CLAUDE.md`, `docs/`, and `public/assets/` keep the same relative paths.

Then launch Claude Code from the repository root and say:

> Read `CLAUDE.md` and every required project document. Inspect the repository and supplied assets. Perform Phase 0 only. Do not modify application code. Produce the Phase 0 planning documents, report risks and gaps, then stop for approval.

## Important hero note
`public/assets/hero/hero-sanctuary-level1-3840x2160.jpg` is a **dimension-contract derivative** created from the generated source image. The native generated source is 1672×941, so the 3840×2160 file is suitable for Phase-2 layout/motion validation but is not a true additional-detail 4K render. Before final production launch, replace it with a true high-resolution master or professional super-resolution output.
